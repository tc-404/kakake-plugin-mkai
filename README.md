## 这是什么

MK_AI 是一个运行在 **咔咔珂（Kakake / MKcc）** 上的独立 AI 聊天插件，插件 ID 为 `kakake-plugin-mkai`。

它让机器人在群聊和私聊里像真人一样接话：会看上下文、记得住事、能联网查资料、能认图、能发自己的表情包、还能用语音回你。所有开关和参数都在一套 **React 可视化后台**里点，不需要登服务器改文件。

> 群内**没有**任何开关指令。想让机器人在哪个群说话，去后台「聊天开关」打开它 —— 不打开就不会回复。

## ✨ 功能特性

### 🤖 多厂商模型接入

| 线路 | 说明 |
| --- | --- |
| **深度求索** | DeepSeek 全系模型 |
| **英伟达 NIM** | NVIDIA NIM 推理服务 |
| **自定义厂商** | 任何 OpenAI 兼容接口，填 `base_url` + `api_key` 即可 |

支持一键**测试访问**、**拉取模型列表**，不用手动猜模型名。还能配**模型轮替**，让多个线路按策略轮流用。

### 💬 像真人一样聊天

- **消息缓冲防抖** —— 群里连刷十几条不会触发十几次回复，攒齐了一次性理解
- **上下文管理** —— 长对话自动压缩，既省 token 又不断片
- **人设系统** —— 自定义人格与说话风格，支持风格多样性避免复读
- **场景判断** —— 会判断该不该插话，该沉默时安静，不刷屏
- **会话隔离** —— 每个群 / 每个人独立记忆，互不串味
- **前缀缓存** —— 命中缓存显著省钱，长对话成本可控

### 🧠 能力扩展

- **联网检索** —— Tavily / Serper / 博查 三家搜索源可选
- **图片识别** —— 群里发的图直接读进上下文
- **文件识别** —— 群文件支持 `txt/js/mjs/ts/go/sh/bat/log`，单个 ≤500KB（只读不运行）
- **表情包** —— 内置图库，机器人能发自己的表情，支持按语义模糊匹配
- **贴表情** —— 会给你发的那条消息贴表情回应
- **语音输出** —— 第三方配音（pearapi）或 QQ 官方语音

### 🛡️ 运维友好

- **黑户管理** —— 拉黑指定用户 / 群，屏蔽骚扰
- **聊天开关** —— 按群 / 好友独立启停，支持批量操作
- **数据总览** —— 余额、用量、token 消耗一眼看清
- **会话管理** —— 查看和管理历史会话

## 🚀 快速开始

### 一、安装插件

**方式 A：用打包好的 zip（推荐）**

1. 下载 `kakake-plugin-mkai-1.4.0.zip`
2. 解压到 Kakake 的插件目录
3. 在控制台里加载插件

**方式 B：从源码构建**

```bat
install-build.bat
```

或者手动：

```bash
npm install
npm run build
```

构建产物在 `kakake-plugin-mkai/`，打包成 zip 用：

```bash
npm run pack
```

### 二、配置并使用

1. 打开控制台里的「智能对话」插件页
2. 进 **配置 → 模型接入**，填好 API 密钥并保存
3. 进 **配置 → 对话策略**，按喜好设人设
4. 最后进 **运维 → 聊天开关**，打开你想让机器人说话的群 / 好友

> ⚠️ 第 4 步不能忘 —— 没打开开关的会话，机器人不会有任何回复。

## 📖 详细说明

### 表情图库安装源

后台「能力扩展 → 表情图库」点「安装 / 重新安装」时，会先弹窗让你选下载源：

| 源 | 说明 |
| --- | --- |
| **kakake 服务器**（默认） | 插件内置域名，国内直连一般更快 |
| **GitHub 仓库** | GitHub Releases 直链，源站更新更及时（可能需要代理） |

两个源装出来的内容一致，只是下载路径不同。网络不通时换另一个源试试。

### 数据目录

数据相对本插件的 `dataPath` 存放：

```text
筱筱吖/扩展功能/智能对话/
```

配置、会话、开关、表情图库都在这里。

> 若与其它插件共用同一个 `dataPath`，数据会互相可见。需要隔离时请为 MK_AI 单独指定数据目录。

### 失败与重试

- 上游失败（超时 / 429 / 空响应 / 连接被拒）**不会丢消息**：整批放回缓冲，按 5s→10s→20s→40s→60s 退避重试
- 退避期间只有「被 @」能穿透；连续失败 ≥3 次后连 @ 也不穿透（避免把坏上游打成雪崩）
- 「返头后 body 挂着不结束」会被截止时间中止，不会让会话永久卡住
- 上下文触顶时自动压缩后重试一次

### 安全边界

- 面板路由的 `chatId` / `fingerprint` 走白名单校验，落盘层再断言「路径必须留在数据目录内」
- 「测试访问 / 拉模型列表」只在 `base_url` 与本地已存端点一致时才代入已存密钥
- 改 `base_url` / `balance_url` 的主机时，必须同时重填 `api_key`（否则返回 400）
- ⚠️ 密钥在 `config.json` 里是**明文**存储（面板只显示掩码）。共用 `dataPath` 的部署请自行隔离目录

## 🔧 环境要求

- **宿主**：Kakake / MKcc，需提供 `router`（控制台）才能注册后台页与 API（前缀 `/mkai`）
- **Node.js**：仅构建时需要（`npm install && npm run build`）
- **运行时依赖**：`extract-zip`（装表情图库用）

## 🛠️ 开发

### 项目结构

```text
src/              宿主端源码（TypeScript）
  auth/           智能对话核心：会话、压缩、人设、语音、表情、联网…
  ai/             暴露给模型的 MKAPI 工具（群详情 / 群文件）
  lib/            基础设施（消息收发、数据落盘、后台注册）
webui-src/        后台前端源码（React + TS）—— 人要改的是这里
  pages/          页面
  shell/          桌面/手机壳、导航、弹层
  controllers/    页面控制器（逻辑与视图分离）
scripts/          构建与校验脚本
webui/            后台前端的构建产物（自动生成，已 gitignore）
kakake-plugin-mkai/  打包产物目录（自动生成，已 gitignore）
```

#### 关于 `webui/` 和 `webui-src/`

两者的关系就是「源码 → 产物」，别把它们当成重复文件夹：

- **`webui-src/`** —— 你手写的 React + TypeScript 源码，**改行为改这里**
- **`webui/`** —— `npm run build` 生成的 `remote.js`（单个压缩文件），宿主动态 import 的就是它；**手改会被下次构建覆盖**

之所以不合并：产物目录的 `emptyOutDir` 会清空同目录内容，而 `src/lib/webui.ts` 的静态资源路由也硬绑在 `webui` 这个相对路径上，合并会让「清产物」和「留源码」互相打架。现在的做法是把它们都写进 `.gitignore` —— 克隆下来只需 `npm install && npm run build` 就能重新生成，仓库里只保留源码。

### 常用命令

```bash
npm run build        # 类型检查 + 构建宿主端与后台前端
npm run pack         # 校验 + 打包 zip
npm run typecheck    # 前端类型检查
npm test             # 跑全部验收用例（= verify:all）
npm run verify:list  # 只列出会跑哪些用例
```

### 关于验收用例

`npm run verify:all` 会自动收集 `scripts/verify-*.mjs`，新增脚本不会漏跑。

其中一部分是**真跑源码**的断言 —— 用 esbuild 把真实的 `.ts` 打包后 import 进来再调函数，能真正防住「阈值改了、分支反了」这类问题。

> 依赖真实运行日志的 `verify-force-speak-log.mjs` 未设 `MKAI_LOG_DIR` 时会显示 `SKIP`，属正常现象。

### 关于版本号

发布新版本时，请把 `package.json`、`plugin.json`、`package-lock.json`（顶层 + `packages[""].version` 共两处）的 `version` 一起递增。

打包脚本会交叉校验 `package.json` ↔ `plugin.json`，不一致会直接拒绝出包；但 `package-lock.json` 不在门禁覆盖内，需要手动带上。
